# Starship

Starship is the minimal, blazing-fast, and infinitely customizable prompt for your shell.

## Original Author
The original author of Starship is [Saurabh Singh](https://starship.rs).

## Documentation
For more details, please refer to the [Starship documentation](https://starship.rs/docs/).

## Installation
Follow the [installation instructions](https://starship.rs/guide/#getting-started) to set up Starship in your system.

## Usage
Starship can be used in various shells such as bash, zsh, fish, and powershell. The configuration is simple and easy to modify.
